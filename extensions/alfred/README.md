# Monorail by Ashforde® for Alfred

Type `mr` and part of an action, saved layout, app pair or template.

1. In Monorail, open **Settings → Automation** and turn on **Local API**.
2. Build the workflow: `cd extensions/alfred/Monorail && zip -r ../Monorail.alfredworkflow .`
   then double-click `Monorail.alfredworkflow`.
